# 筛选与排序交互方案

状态：产品设计与交互原型，尚未接入正式应用。

## 入口与面板

- 列表保留“筛选与排序”单入口，激活时高亮；不将按钮拆到列表工具栏。
- 一个面板内设置“筛选”和“排序”标签页，显示当前配置的规则数量。排序数量包含默认排序，禁用的筛选条件不计数；草稿中的无效条件另行标记为待完善。
- 文件夹和归档范围是面板公共设置。范围与条件一起计算；清除筛选、恢复默认排序均不改变范围。
- 默认平铺条件，只显示已添加的字段。添加字段支持按名称搜索，并区分内置字段和自定义属性。
- 自定义属性沿用现有的“允许筛选/排序”设置，决定是否出现在添加菜单。已有配置引用的字段即使关闭该开关也继续显示，不产生无法删除的隐藏规则。
- 输入在草稿中编辑，底部实时预览匹配数量；只有“应用”更新列表。“取消”、关闭按钮、Escape、点击遮罩均放弃本次草稿。
- 切换标签页保留草稿。重新打开时从已应用规则初始化，停留在上次使用的标签页。
- 已应用条件在列表显示可编辑、可移除的摘要；分组条件显示分组摘要，避免用平铺标签歪曲逻辑。窄列表折叠为可展开的“+N”。

## 字段与判断条件

| 字段类别 | 判断条件 | 输入 |
| --- | --- | --- |
| 状态、普通单选 | 属于、不属于、未设置、已设置 | 前两项为多选；同一行多选值按“任一”匹配 |
| 优先级、有序单选 | 等于、不等于、属于、不属于、高于、不低于、低于、不高于、未设置、已设置 | 等级比较单选；属于与不属于多选 |
| 标签、多选 | 包含任意、包含全部、不包含任意、不包含全部、完全一致、未设置、已设置 | 多选值 |
| 标题、文件名、文本、长文本、URL | 包含、不包含、等于、不等于、开头是、结尾是、未设置、已设置 | 文本；标题、文件名不提供空值判断 |
| 数字 | 等于、不等于、大于、大于等于、小于、小于等于、介于、不介于、未设置、已设置 | 数值或上下界，支持 0 与负数 |
| 日期、日期时间、创建时间、更新时间 | 是、不是、早于、晚于、不晚于、不早于、介于、不介于、相对时间、未设置、已设置 | 日期/时间、范围或相对时间；创建与更新时间不提供空值判断 |
| 布尔 | 是、否、未设置、已设置 | 不需要额外值输入 |
| 文件夹 | 公共范围选择：所有文件夹或指定文件夹，指定时可选是否包含子文件夹 | 文件夹选择器 |
| 归档 | 公共范围选择：未归档、已归档、全部 | 单选 |

优先级不是所有单选字段的默认语义。属性需要明确标记为“有序选项”，并显示、允许配置等级顺序。状态仅使用集合判断，不因显示顺序而获得大小关系。

相对时间提供今天、昨天、本周、本月、过去 N 天、未来 N 天、早于 N 天前。日历日期按本地自然日计算，日期时间按本地时间展示并按统一时间点比较。“过去 N 天”含今天、“未来 N 天”含今天；“早于 N 天前”为严格边界。相对条件保存表达式，重新查询时求值，不固化为保存当天的日期。

范围默认含上下界。日期条件“是某天”覆盖当天全部时间；“晚于某天”从次日开始。日期时间支持精确到分钟；存储与比较时保留原有精度，输入“是某分钟”覆盖该分钟。

## 条件组合

- 根条件可选“全部满足（AND）”或“任一满足（OR）”。
- 可添加条件组；组内独立选择 AND / OR，并支持进一步分组。例如：`（状态属于待办/进行中）AND（优先级不低于中 OR 截止日期为今天）`。
- 条件可以编辑字段、运算符和值、复制、删除、临时禁用。字段变化时重置不兼容的运算符与值，不保留类型不符的隐形值。
- 空组不参与判断，保存时移除；没有有效条件表示不限制。禁用条件保留配置但不参与匹配，组内只有禁用条件时视为空组。
- 重复条件可以有意存在，例如同一数字字段设置上下界；不自动去重或改写用户的逻辑。

## 空值与否定条件

- 未设置包括缺失、null、空白字符串与空数组。数字 0、布尔 false 均为已设置。
- 所有普通比较，包括“不等于”“不属于”“不包含”，只匹配已设置的值。需要包含未设置项时，显式使用 OR 加“未设置”。
- “不包含任意 A/B”表示 A、B 都没有；“不包含全部 A/B”表示至少缺少一个。已设置的集合参与判断，空集合归入“未设置”。
- 文本比较不区分大小写；去除输入首尾空白，保留内部空格。标签、状态按选项 ID 判断；排序及等级比较按选项配置顺序，绝不按 ID 的字典序比较。
- 不能将缺失优先级当作最低优先级，也不能将缺失日期当成过期日期。
- 任务中的字段值若类型错误或引用已删除的选项，保留原数据并提示修复；不参与普通比较，排序按空值位置处理，不把错误值当作最低等级或合法数字。

## 排序

- 快捷项：最近更新、最近创建、标题 A–Z、标题 Z–A、优先级高到低、截止日期最近优先（空值最后）。快捷项明确替换当前排序规则，不暗中叠加，不改变筛选结果数量。
- 自定义排序按从上到下的优先级执行；每行分开选择字段、方向、空值位置，可添加、删除、上移、下移。支持键盘与按钮调整顺序，无须依赖拖拽。
- 同一字段只能出现一次；已使用字段不可重复添加。
- 可排序：标题、文件名、文件夹、创建/更新时间、日期/日期时间、数字、布尔、短文本、URL、单选与有序单选。长文本、标签和多选默认不参与排序，避免没有清楚定义的数组/长文本比较。
- 显示按类型命名的方向：A–Z/Z–A、最新/最早、最近到期/最晚到期、高到低/低到高、大到小/小到大、是优先/否优先、选项顺序/反向选项顺序。
- 每一条独立设置“空值最后/空值最前”。空值位置不随升降序翻转；无空值的内置字段隐藏此设置。
- 标题使用中文本地化自然排序，数字片段按数值排列，如任务 2 排在任务 10 前。文本按同一规则；日期按时间比较；普通单选按配置顺序；布尔 false < true。
- 所有显式排序相同后依次按更新时间降序、标题自然升序、稳定任务 ID 排列，保证重复查询一致。默认排序为更新时间降序。
- 清空最后一条排序时恢复默认排序；“恢复默认排序”不改变筛选、文件夹、归档范围。

## 保存与恢复

- 复用现有保存视图机制，不新建第二套收藏系统。视图保存范围、条件树和有序排序列表，名称必填且在当前工作区不重复。
- 面板支持“应用并保存为视图”；已有关联视图修改后显示“已修改”，可更新该视图、另存为或恢复其已保存配置。列表现有视图菜单负责切换、重命名和删除。
- 每个工作区独立记忆最后应用的配置，不因取消编辑而覆盖。归档范围和文件夹随视图恢复。
- 保存失败时保留草稿与名称，允许重试；视图文件被外部修改时提示冲突并重新读取，不能静默覆盖他人的更新。
- 字段/选项/文件夹删除或类型改变后，保留原规则并指出失效位置，阻止应用或保存，允许用户修复或删除，绝不静默忽略。
- 旧的平铺 filters 按 AND 导入；旧 sorts 原样保留；旧视图可继续读取，写入新条件树时带版本。正式实现需要同步升级前端、Rust 查询模型和视图序列化。

## 校验、反馈与可访问性

- 未填值、空选项、非法数字、范围倒置、无效日期、非正整数相对天数均行内报错，暂不执行不完整查询；计数显示“—”，应用与保存禁用。
- 零匹配是合法结果；面板提示“没有匹配任务”，仍允许应用。列表提供“修改条件”和“清除筛选”，保留当前范围。
- 已应用规则摘要、匹配数量、保存状态可见。计数加载时显示加载状态，查询失败保留草稿与已有列表，并提供重试。
- 文本输入防抖约 250ms；只接受最新请求结果，避免旧请求覆盖。背景刷新保留列表与选中任务，不出现整页加载闪烁。
- 应用后保留仍在结果中的选中任务与滚动位置；选中任务不再匹配时，编辑器可继续显示该任务，并提示“不在当前筛选结果中”，不强制丢弃编辑。
- 面板有可访问名称、焦点约束与关闭后的焦点返回。标签页支持方向键，所有动作可使用键盘，不能仅凭颜色区分规则状态。

## 正式实现验收

1. 每类运算符覆盖命中、不命中、空值、0/false、中文和边界值，确保前端演示与 Rust 查询语义一致。
2. AND/OR、嵌套组、禁用与空组计算正确；无效条件不能意外变成“全部任务”。
3. 多字段优先级、空值位置、自然排序及稳定兜底可重复验证。
4. 应用、取消、关闭、切页和视图切换不会混淆草稿与已应用配置；失效引用不会悄悄扩大结果集。
5. 用真实 Tauri WDIO 流程验证从面板配置到原生查询、列表结果及持久化恢复，保留回归测试。
